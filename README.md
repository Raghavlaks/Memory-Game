Flipo Flip
Memory Matching Game built using HTML, CSS and JavaScript

About the Project:
Flipo Flip is a simple memory card game built using HTML, CSS and JavaScript with direct DOM manipulation. This project was created as a hands-on exercise to understand how interactive game logic works 
in the browser without using any frameworks or external libraries. The focus of this project is on implementing game logic, handling user interactions and updating the UI dynamically.

I Worked On:

1. Implemented game logic using JavaScript and DOM manipulation
2. Handled card flipping, matching logic and board lock conditions
3. Built a countdown timer and restart functionality
4. Tracked moves and matched pairs during gameplay
5. Designed the UI using CSS animations and layout styling

Key Features:

1. Cards are shuffled every time the game starts or restarts
2. Smooth card flip animation using CSS transforms
3. Timer displayed in HH:MM:SS format
4. Move counter and pair counter
5. Restart option that resets the entire game state

Tech I Used:

1. HTML for structure
2. CSS for layout and animations
3. JavaScript for game logic and DOM manipulation
4. No frameworks or external libraries were used.
